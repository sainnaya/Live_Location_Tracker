# 📍 Live Location Tracker

A real-time web application that allows users to share and visualize live location updates through a simple link-based experience.

## ✨ Features

- 📍 Real-time location tracking
- 🔄 Live location synchronization using Socket.IO
- 🗺️ Interactive map-based location visualization
- 🔗 Link-based location sharing
- 👤 Simple user name input
- 🌿 Modern and responsive nature-inspired UI
- ✨ Animated recipient experience
- 🔐 Environment-based configuration for sensitive credentials
- 📱 Mobile-friendly design
- ⚡ Real-time updates without refreshing the page

## 🛠️ Tech Stack

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js
- Socket.IO

### Database
- MongoDB

### Other Tools
- Git & GitHub
- Cloudflare Tunnel
